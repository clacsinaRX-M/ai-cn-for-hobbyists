# Cloud Native + AI Resources for Hobbyists

A curated list of websites, tutorials, and training pages that explore Kubernetes and AI from a hobbyist perspective. This collection focuses on things you can actually build or experiment with, such as local clusters, homelabs, model serving, notebooks, Ollama deployments, and beginner-friendly distributed ML.

## Hobbyist Projects

- [SkyPilot: AI on Kubernetes Without the Pain](https://blog.skypilot.co/ai-on-kubernetes/)
A practical overview of running AI workloads on Kubernetes, including ideas for local development, training, and serving.
- [AI \& Kubernetes - Containerized Adventures](https://kaslin.rocks/ai-kubernetes/)
A readable introduction to how Kubernetes fits AI training, inference, and deployment workflows.
- [Deploying Local AI Agents in Kubernetes](https://www.cloudnativedeepdive.com/deploying-local-ai-agents-in-kubernetes/)
A useful resource if you want to run local AI agents inside a Kubernetes environment.
- [Build Your Own Private "ChatGPT" with Kubernetes and Ollama](https://dev.to/romulofrancas/unlock-the-future-build-your-own-private-chatgpt-in-30-minutes-with-kubernetes-ollama-and-1npp)
A hobbyist-friendly project for building a private LLM setup on K3s.
- [Ollama Kubernetes Deployment: Cost-Effective and Secure](https://mykubert.com/blog/ollama-kubernetes-deployment-cost-effective-and-secure/)
A practical guide for deploying Ollama on Kubernetes.
- [feiskyer/ollama-kubernetes](https://github.com/feiskyer/ollama-kubernetes)
A GitHub repository with Helm-based deployment resources for Ollama on Kubernetes.
- [Deploying OpenAI's GPT-OSS model on Kubernetes with Ollama](https://www.madhan.app/blogs/035-gpt-oss-k8s-ollama/)
A hands-on example of serving a model with Ollama in Kubernetes.
- [Your Own AI Cloud: Deploying AI Models in a Kubernetes Homelab!](https://www.youtube.com/watch?v=_v0qhWc1qJ0)
A video resource showing how to build an AI-serving homelab on Kubernetes.


## Learn the Cluster First

- [Kubernetes 102: Setting Up Your First Cluster and Core Concepts](https://dev.to/alikhere/kubernetes-102-setting-up-your-first-cluster-and-core-concepts-52j5)
A beginner-friendly walkthrough using K3s to explain the basics before adding AI workloads.
- [How to Create a Local Kubernetes Cluster with Kind](https://dev.to/klaus82/how-to-create-a-local-kubernetes-cluster-with-kind-5bfj)
A simple tutorial for spinning up a local Kubernetes cluster for testing and experimentation.
- [Building a Kubernetes Home Lab from the Ground Up](https://obot.ai/blog/building-a-kubernetes-home-lab-from-the-ground-up/)
A solid resource for building a home lab that can host services and AI experiments.
- [Homelab, 2024 stage 4 Kubernetes](https://blog.ayjc.net/posts/homelab-2024-stage-4-k8s/)
A real-world homelab write-up that includes a GPU node for AI-related work.
- [Building a cheap AI/ML machine to run on a homelab kubernetes cluster](https://ianbelcher.me/tech-blog/building-a-cheap-ai-ml-machine/)
A good starting point if you want affordable hardware for AI on Kubernetes.


## AI Tooling on Kubernetes

- [Kubeflow Quickstart Guide](https://www.kubeflow.org/docs/components/notebooks/quickstart-guide/)
The official quickstart for running notebook-based ML workflows on Kubernetes.
- [Get up and Running with Kubeflow on Kubernetes](https://www.civo.com/learn/get-up-and-running-with-kubeflow-on-civo-kubernetes)
A beginner-oriented guide to launching Kubeflow and notebooks on a Kubernetes cluster.
- [Deploy Jupyter Notebooks on Kubeflow](https://docs.kakaocloud.com/en/tutorial/machine-learning-ai/kubeflow-jupyter-notebook)
A step-by-step tutorial for setting up Kubeflow and Jupyter notebooks.
- [How to Get Started with Kubeflow on Kubernetes](https://oneuptime.com/blog/post/2026-01-26-kubeflow-kubernetes/view)
A broader guide covering notebooks, pipelines, and model-serving features.
- [Deploy ML Model on Kubernetes with KServe](https://devopscube.com/deploy-ml-model-kubernetes-kserve/)
A practical step-by-step guide for serving models with KServe.
- [TensorFlow Model Serving using KServe: A Step by Step Guide](https://ashutoshtripathi.com/2024/05/26/tensorflow-model-serving-using-kserve-a-step-by-step-guide/)
A local-first tutorial using Minikube and KServe.
- [Run with Kubernetes and KServe ModelMesh Serving](https://www.ibm.com/docs/en/watson-libraries?topic=containers-run-kubernetes-kserve-modelmesh-serving)
A reference-style guide for learning KServe and ModelMesh serving patterns.
